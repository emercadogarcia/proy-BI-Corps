¡Tu herramienta ETL está lista! 🚀 Aquí lo que hace en 4 pasos:
01 EXTRACT — Arrastra o selecciona tu archivo .xls / .xlsx. Detecta todas las hojas automáticamente y muestra una vista previa de los datos.

02 TRANSFORM — Opciones configurables: encoding UTF-8 con BOM, trim de espacios, incluir encabezados, y omitir filas vacías.

03 EXPORT CSV — Descarga el archivo convertido como nombre_utf8.csv listo para usar en cualquier sistema.

04 N8N FLOW — Genera automáticamente un JSON de flujo n8n con 5 nodos (Read → Extract → Transform → Write → Save) que puedes importar directo en n8n desde Workflows → Import from JSON.
